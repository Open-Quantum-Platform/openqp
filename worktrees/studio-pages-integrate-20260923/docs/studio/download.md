# Download OQP Studio

Choose your operating system below. The **with-engine** installer includes
OpenQP and works without a separate engine download. A **standard** installer
uses a separately installed local or remote engine.

## Independent Studio releases

This page is the stable entry point for Studio downloads. Future Studio
releases will be versioned separately from OpenQP and offered here after
Windows, macOS and Linux qualification. The existing downloads above will
remain available during that transition.

**Stable** will identify a tested Studio and engine combination. **Preview**
will be explicitly labelled and offered separately; it will not replace Stable
or silently update an installed engine. No independent Stable or Preview
release is available from this page yet.

Each new release will identify the Studio version, bundled engine version and
exact engine commit. See [engine compatibility](engine-compatibility.md).
