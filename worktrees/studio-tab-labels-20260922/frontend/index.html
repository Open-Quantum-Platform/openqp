          Network settings
          
        

        

          Campus and company networks often inspect encrypted traffic by re-signing
          it with their own root certificate. PubChem lookups fail until OQP Studio
          trusts that root. Sketching and typing coordinates never need the network.
        

        

        
        

          
          
        

        
        
        

          Last resort. Traffic stays encrypted, but the app stops checking who it is
          talking to. Only switch this on for a network you already trust.
        

        

          
          
          
        

      

    


    
    

      

        

          Results folder
          
        

        

          Every run gets a folder of its own here, holding its input, log, JSON
          export and any molden file. Pick somewhere you can find again.
