OpenQP Python API
=================

Open Quantum Platform (OpenQP) is a quantum-chemistry platform centered on
mixed-reference spin-flip TDDFT and interoperable ground- and excited-state
workflows.

This reference is generated statically from the Python source on the current
``main`` branch (OpenQP 1.2.1). It includes the high-level :class:`OpenQP`
interface, semantic input handling, analysis and export helpers, quantum
integral tools, molecular data models, and workflow implementations.
