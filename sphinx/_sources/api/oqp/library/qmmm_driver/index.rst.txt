.. py:class:: OpenQpQMMM(positions, topology, forcefield, qm_atoms, oqp_cfg=None, mol=None, Cutoff=app.NoCutoff, Embedding='mechanical', frontier_scheme='none')

   .. code-block:: text

      Low-level QM/MM driver using OpenMM (MM) + OpenQP (QM).

      Two modes:
        1. **Config mode** – ``oqp_cfg`` (dict).
        2. **Mol mode**    – pre-built ``mol`` object.

      Exactly one of ``oqp_cfg`` / ``mol`` must be provided.
